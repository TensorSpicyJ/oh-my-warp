# omw-windows

> Cloud-stripped Warp terminal for Windows. Zero cloud, zero phoning home.

## What this is

omw-windows 是 [oh-my-warp](https://github.com/AndrewWayne/oh-my-warp) 的 Windows 移植版。编译期裁掉所有 warp.dev / Firebase / Oz 云端依赖，出审计干净的本地终端二进制。

基于 [Warp](https://github.com/warpdotdev/warp)（AGPL-3.0），本 repo 是 Warp 的 fork。

## Status

**v0.0.0** — 编译 + 审计 + 便携打包。omw-server / omw-agent / research-agents 延后。
